Wall

Work down the page like the job: plates, then the openings, then corners, backing and studs. A row goes into the wall as soon as you press Enter (or pick from a list) - if it has to wait for something, it says what. Come back and change any row any time. Keep the Tape Measure handy: measure the openings on the table for cripples, headers and header blocks. Lengths: 92 5/8 or 7' 8-5/8". Plates over 16' get spliced - type each piece from the layout start with a comma between.
